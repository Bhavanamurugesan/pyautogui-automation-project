# GUI Automation using PyAutoGUI

## 1. Project Overview

This project demonstrates GUI automation using Python and PyAutoGUI.
The automation script simulates user actions such as opening an application, typing information, saving files, capturing screenshots, and closing the application automatically.

This project shows how automation can reduce repetitive manual tasks and improve efficiency in workflow operations.

---

## 2. Problem Statement

In many organizations, employees perform repetitive GUI-based tasks such as:

* Opening applications
* Entering customer details
* Saving files manually
* Capturing screenshots for documentation

Performing these tasks repeatedly can consume time and may lead to human errors.

---

## 3. Proposed Solution

To address this problem, a Python automation script was developed using the PyAutoGUI library.

The script automates the entire workflow by performing keyboard and mouse actions programmatically.

---

## 4. Features

The automation script performs the following tasks automatically:

* Opens Notepad
* Types customer case details
* Saves the file
* Takes a screenshot
* Closes the application

---

## 5. Technologies Used

* Python
* PyAutoGUI
* Visual Studio Code
* GitHub

---

## 6. Installation

Install the required library using the following command:

pip install pyautogui

---

## 7. How to Run the Project

Run the automation script using the command below:

python automation_demo.py

The script will automatically perform the following workflow:

1. Open Notepad
2. Enter customer details
3. Save the text file
4. Capture a screenshot
5. Close the application
